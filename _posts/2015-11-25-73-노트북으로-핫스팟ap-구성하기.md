> 💡 **TL;DR (핵심 요약)**  
> 노트북으로 핫스팟(AP) 구성하기에 대한 상세 설명 및 핵심 가이드입니다.

---

## 1. 개요 및 배경

노트북으로 핫스팟(AP) 구성하기 가이드 및 실무 적용 설명입니다.

---

## 2. 핵심 설정 및 실행 가이드

**1\. 관리자 권한으로 명령 프롬프트(cmd.exe)를 실행한다.**

  


![](/assets/img/posts/img_73_01.png)

  


  


**2\. 지원되는 랜카드 인지 확인하기**

> netsh wlan show drivers

호스트된 네트워크 지원에 '예' 라고 표시되는 경우 사용 가능하다.

  


![](/assets/img/posts/img_73_02.png)

  


  


**3\. SSID와 패스워드 지정하기**

> netsh wlan set hostednetwork mode=allow ssid=아이디 key=패스워드

  


![](/assets/img/posts/img_73_03.png)

  


  


**4\. 핫스팟 실행**

> netsh wlan start hostednetwork

  


![](/assets/img/posts/img_73_04.png)

  


  


**5\. [제어판 > 네트워크 및 인터넷 > 네트워크 연결]에 새로운 네트워크 장치가 생성됨을 확인할 수 있다.**

  


![](/assets/img/posts/img_73_05.png)

  


  


**6\. 기존에 인터넷과 연결되어 있던 장치의 속성으로 들어간다.**

(새 장치의 인터넷 사용을 위해 네트워크를 공유하기 위함이다. )

  


![](/assets/img/posts/img_73_06.png)

  


  


**7\. 공유탭에서 인터넷 연결 공유에 체크한 후, 5번 과정에서 새로 발견된 장치를 연결시켜 주면 모든 구성이 끝난다.**

  


![](/assets/img/posts/img_73_07.png)

  


  


**8\. 설정 확인**

> netsh wlan show hostednetwork

(구성한 AP에 붙은 클라이언트 수 등을 확인할 수 있다.)

  


![](/assets/img/posts/img_73_08.png)

  


  


**9\. 핫스팟 중지하기**

> netsh wlan stop hostednetwork

  


![](/assets/img/posts/img_73_09.png)

  


  


**10\. 핫스팟 제거하기**

> netsh wlan set hostednetwork mode=disallow

  


![](/assets/img/posts/img_73_10.png)

  


*** 정리**

  


지원여부확인 : netsh wlan show drivers

  


설정 : netsh wlan set hostednetwork mode=allow ssid=아이디 key=패스워드

  


시작 : netsh wlan start hostednetwork

  


상태 : netsh wlan show hostednetwork

  


중지 : netsh wlan stop hostednetwork

  


제거 : netsh wlan set hostednetwork mode=disallow
