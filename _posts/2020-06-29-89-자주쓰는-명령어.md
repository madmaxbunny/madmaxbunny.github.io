## 2. 핵심 설명 및 설정 가이드

네트워크 스캔

1) Winodws

```bash
netstat -ano | findstr 8080
```

2) Linuix

```bash
netstat -ant | gtep LISTEN
```

1) TCP만 확인 : netstat -at

2) UDP만 확인 : netstat -au

3) Mac

```bash
lsof -iTCP:8093 -sTCP:LISTEN
```

**Linux**

CentOS 버전 확인

> cat /etc/redhat-release

**네트워크 스캔****> netstat -ant | gtep LISTEN**

1) TCP만 확인하기 > netstat -at

2) UDP만 확인하기 > netstat -au

**yum 넥서스 주소 적용**

/etc/yum.repos.d 폴더 내 *.repo 파일 생성

예제)

```bash
[base]
name=CentOS-$releasever - Base
baseurl=https://...
gpgcheck=0
enabled=1
gpgkey=https://...
```

SMB 접속 테스트

> smbclient //IP주소/MobileShare -U 도메인/계정명

* \가 아닌 / 로 입력해야 함

**포트 오픈 확인**

CentOS : nc 아이피 포트

패스워드 변경

sudo passwd <계정명>

* * *

**Apache HTTP Server**

1) 버전확인

$ httpd -v

2) 시작

$ systemctl start httpd   
$ service httpd start   
$ apachectl start

3) 종료

$ systemctl stop httpd   
$ service httpd stop   
$ apachectl stop

4) 재시작

$ systemctl restart httpd   
$ service httpd restart   
$ apachectl restart

아파치 httpd 오류 체크

> service httpd configtest

> httpd -t

**Tomcat 버전 확인**

TOMCAT_HOME\lib 폴더에서

> java -cp catalina.jar org.apache.catalina.util.ServerInfo
