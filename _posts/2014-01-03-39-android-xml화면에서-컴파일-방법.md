## 1. 개요 및 배경

[Android] XML화면에서 컴파일 방법과 관련해 개발 및 인프라 운용 과정에서 알게 된 점들을 공유해요.

---

## 2. 핵심 설명 및 코드

Windows -> Preferences -> Run/Debug -> Launching  
: Launch Operation에서 Always launch the previously launched application 선택  
  
Windows -> Preferences -> Run/Debug -> Launching -> Launch Configurations  
:Filter check launch configuration types: 체크 후, 가장 하단에 있는 XSL체크  
  
Apply 후 종료
