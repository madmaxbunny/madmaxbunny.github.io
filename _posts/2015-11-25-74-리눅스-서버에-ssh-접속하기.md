**2\. 서버에 ssh 설치하기**

> sudo apt-get install openssh-client

> sudo apt-get install openssh-server

> sudo /etc/init.d/ssh restart

  


**3\. 암호 설정**

1) 암호로 ssh 접속하기

> sudo passwd root

여기서 설정한 암호와 비밀번호로 ssh에 접속하면 된다.

  


2) 암호없이 ssh 접속하기

(2) 키를 확인한다.

> ls -al ~/.ssh/

id_rsa : 개인키(비밀키)

id_rsa.pub : 공개키 - 접속하려는 클라이언트의 authorized_keys에 입력한다.
