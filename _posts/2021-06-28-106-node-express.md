## 2. 핵심 설명 및 설정 가이드

1\. 설치

```javascript
> npm install express --save
```

2\. app.js

```javascript
const express = require('express')
const app = express()
const port = 3000

app.use(express.static(__dirname + '/web'));

app.listen(port, () => {
  console.log("server running... ");
})
```

3\. 실행

```javascript
> node app.js
```
